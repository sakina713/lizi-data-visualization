# 密集流程图：信息分区与指向关系

从招聘漏斗参考提炼用户确认的原则：数值较多时可适当使用左右结构和指向线，使信息与图形清楚对应。参考只提供排布思路，不限定三列宽度、颜色、椭圆截面、渐变或阶段数。

## 先确认数据关系，再安排信息

- 可追踪的同口径阶段适合漏斗；非子集的供需比较或汇入流程要明确其含义，必要时用步骤/流程图，而非强制逐级收窄。
- 阶段数量与环节效率是两种信息：数量对应一个阶段，效率对应起止阶段之间的关系。布局和连线必须反映这种区别，不能仅按同一行就近猜测。
- 比例由真实分子分母计算。满足率可以超过100%，不应被当作必然递减的转化率；没有依据不补造转换环节。

## 根据密度选择布局

| 情况 | 优先处理 |
| --- | --- |
| 阶段少、信息简单 | 就近放标签，不为套参考强制左右分区 |
| 阶段数量＋环节效率＋基准同时出现 | 可将阶段信息与效率分两侧，中间留图形；也可按阅读顺序交换两侧 |
| 阶段长、比较说明多 | 将每个信息组自适应增高，扩大阶段间隔，必要时把比较明细放到图下 |
| 窄屏或流程很长 | 考虑纵向步骤、分组流程或图表与明细组合，保留清楚的对应标识 |

- 一种清晰的组合是“阶段名称/数量—图形—环节效率/基准”，但只有数据适合时才使用。不是所有图都必须把数量放左、效率放右。
- 阶段名称与数量作为一组，环节名称、当前率、基准与差值作为另一组；组内紧凑、组间分离，延续已有关联间距原则。必要信息外移，不在图形里堆文字。
- 阶段组对准对应阶段，环节组靠近对应起止区间；长文案出现时按实际高度重新布局，不按原稿固定坐标硬塞。
- 名称和次要基准适度弱化，当前数量/效率更醒目；异常依据明确时突出对应效率或提示，不把所有阶段都标红。主题色、字重、字号来自当前规范和业务语义。

## 指向线应解决歧义

- 当标签离开对应图形、就近关系不足以识别时，才使用短指向线；已有明确对齐不必每项补一根线。
- 线锚定真实阶段边界或环节，随图形与布局一起更新。起点避开文字实际边界，终点不指向其他层。
- 优先细、浅、短的直线；需避让时可用简单折线。线条应弱于数据与文字，不穿字、不交叉、不穿过主图，也不与行业提示混在一起。
- 标签对应线通常不需要箭头；只有明确表达方向时使用方向标识。不要让对应线看起来像有流量含义的数据连线。
- 指向线长度和标签位置可以为可读性调整，但不得因此改变真实几何比例、放大最小层或删掉必要阶段。

## 图形美观服从数据表达

- 截面、填充、圆角、渐变、线宽按当前图形和主题决定；不把参考的椭圆造型或顶部虚线固化为所有漏斗的模板。
- 保持连续关系和阶段边界可辨，装饰不应制造额外量级暗示。阶段顺序稳定，颜色不能按数值排名重新分配造成流程错读。
- 默认使用真实比例；参考中的视觉强调形状不能当作数值编码依据。若用户明确选用示意形状，须在读者可见处说明，而非只写在图层名。
- 精简视觉噪音不等于删除必要数量与效率；这类信息通常共同构成判断依据，先分区，再决定是否需要补充明细。仍遵守[按主题选择关键数值](chart-drawing.md#按主题选择关键数值2026-11-10-用户确认)。

## 验收

检查数量—阶段、效率—起止环节是否一一对应；连线不穿字/交叉；文字增高后仍不重叠；语义颜色正确；比例真实或示意说明清楚。手机端先调整布局与总高，不能用裁切或过小字号换取表面整齐。只要清楚表达并保持统一风格，布局不必与参考稿相同。
