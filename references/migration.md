# 旧流程接入与迁移

本技能负责已确认数据的视觉呈现，不负责取数、客户权限、业务阈值定义、证据推断或自动推送。既有数据契约、脚本接口及已审核事实保留在原流程。

- 图表计划、报告组装和视觉回改入口引用本技能，避免各入口复制一份配色、字号或排版规则。
- 迁移时对照字号、数值精度、比较口径、排序与语义色、表头、图标、关联间距和移动端验收；用户最新要求优先，项目特例保留其作用范围。
- 跨项目通过技能名称或实际安装目录找到入口，不依赖原项目的绝对路径或工作区相对路径。
- 通用规则可以独立使用。历史报告的模板、客户配置、内部Figma资料、图标及Logo由各项目提供，不属于本发布包。
- 引用规则不等于运行器已升级。新增图型或自适应行为须在当前实现中完成，并实际渲染验收；不能把旧脚本的能力假定为覆盖所有新规则。
- AntV链接用于选图方法参考，本技能未复制其原文，也未接入其远程渲染服务。
