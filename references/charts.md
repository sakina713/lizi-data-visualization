# 图表规则

尚未确定图形时，按[AntV选图逻辑适配](chart-selection-antv.md)检查数据条件、筛选候选；确定图形后，按[图表绘制原则](chart-drawing.md)统一颜色、圆角、间距、标签和重点。维护已确认报告时保留其任务范围内的决定；分析参考稿时只提炼方法，不将其视为所有新数据的固定图型。

## 先判断关系，再选图

记录当前问题、指标/单位/分母、周期/对象、数据关系、合并或拆分原因、坐标编码和标杆映射。同一单位和口径、共同回答一个问题的值优先同图；不同单位、不可比样本或标注拥挤时拆成相邻子图，不能为了合并拼成误导双轴。

| 数据关系 | 呈现方式及条件 |
| --- | --- |
| 独立KPI | 数字卡，不因同为百分比拼成构成图 |
| 同指标地区/门店/人员比较 | 根据大小比较、长名称、精确查数需求选柱/条、点图或排名表；已有报告的图型变更应在用户授权范围内，不把某个客户的纵柱推广成所有场景默认 |
| 当前与标杆 | 主图内参考线/短标记并直接标值；独立比较可用同轴点图，不另画重复类别 |
| 时间变化 | 真实有序序列用趋势线或堆积柱；两期可用前后对比，无序列不造趋势 |
| 互斥构成 | 同分母且总量核对后环图、饼图或100%堆积图；配人数/金额和比例明细 |
| 阶段承接 | 能追踪的流程用漏斗/步骤图；阶段名称相似或数量递减不足以证明同一人群子集 |
| 来源—去向流转 | 真实流转数据可用桑基/分流图，色带按真实量计算并预留独立标签通道；独立异常率使用比较图，当前报告使用下文已确认的卡片柱图 |
| 时段分布 | 多对象节奏比较可优先考虑[时段热力矩阵](time-distribution.md)；单对象量级、连续变化或精确差值可选柱/折线等。方向、密度、颜色随当前情况适配，不固定复刻参考 |
| 对象×多指标分布 | 可用[带数值的紧凑色块矩阵](distribution-matrix.md)，须说明全表或逐列色阶范围，不与时段矩阵的共同色尺混用 |
| 横向比较、排名、精确查数 | 带表头表格，保留要求的字段及全部行 |
| 案件、事件、处理进度 | 提炼关键字段后使用卡片列表，遵守[记录型信息卡片化](layout-theme.md#记录型信息的卡片化)；对象优先、状态次要，关键事实与结果分层 |

## 排序和颜色

- 无固定业务顺序的分类比较按原值降序，同值稳定排序。时间保持时间顺序，漏斗/进度保持流程顺序，显式业务顺序保留。
- 同指标地区、门店、人员无主次比较时普通项统一C1，不因大小/名次用不同颜色；异常项危险色。有明确关注对象时按[目标突出、参照弱化](chart-drawing.md#目标突出参照弱化)处理，保留对照读数和异常提示，不改变比例或排序。
- 数值热力矩阵是颜色承担数值编码的明确例外，可用同色系深浅表达低到高；它不适用普通柱图“各项统一C1”的限制。不能把矩阵色阶反过来推广为柱图按名次变色，详见[矩阵的色阶与比较范围](distribution-matrix.md)。
- 构成饼/环图及分流普通类型按数值由大到小对应深到浅色阶；最大C1、最小C8，中间按项数均匀选色，单项C1。明确正负语义颜色保留。
- 图例、名称、数值、样本量跟随数据排序及颜色映射；趋势同一系列跨月份颜色固定。构成的颜色差别不能误作业绩优劣。

## 几何与标签

- 数值标签围绕标题关注的指标选择，遵守[按主题选择关键数值](chart-drawing.md#按主题选择关键数值2026-11-10-用户确认)。如高效能占比趋势的堆积柱只标各月高效能系列，其他分段保留图形和图例，不默认给所有色块铺数字；图形数据与标签可见性分开管理。逐格查数的热力矩阵及排名表不套用此精简策略。
- 坐标、条长、角度使用原始值，不使用舍入后的标签再归一化。零基线与量程真实，缺失不是0；不通过放大小项或压低标杆改变业务比例。
- 标杆名称和值保留在纵轴左侧，值中心对齐虚线。与常规刻度冲突时隐藏相邻常规刻度标签，保留量程和映射；不能挪到右上角图例。参考线避开柱顶数字。
- 饼/环从12点方向顺时针排列；边界约2px白线覆盖环带，小扇区适度缩细，单项无分割线。白线不以固定留白吞掉小项。总数、类别值及占比图例一致。
- 饼/环图例按[名称、具体数值与百分比并排](chart-drawing.md#饼环图图例名称具体数值与百分比并排)组织同项信息，以文字颜色和字重区分规模与占比。已有具体值与比例都须保留，不能为减少噪音只留百分比；窄屏调整同项布局，不删除读数或单位。
- 分流按色带厚度和文字高度分配间距；除明确业务含义外不交叉重叠。图形、标签、数字和说明各自可读。
- 漏斗保留准确人数、环节转化和已有比较。真实人数可增加的招聘流程须明确各阶段统计口径，不强行解释成子集递减漏斗。默认真实比例；用户要求强调变化时可用显式强调模式，注明形状强化，不能称为真实比例。标签移到外侧时保持就近，不用随意放大最小层容纳文字。
- 漏斗数值和比较较多时，采用[左侧阶段数量—中间图形—右侧环节效率](funnel-layout.md)布局，以轻量指向线连接阶段截面；转化率对应相邻阶段之间的环节。保持阶段与环节的不同锚点，不把所有数字堆入漏斗内部，也不为美观删去必要比较。
- 当前报告已有趋势与漏斗原稿SVG仅是参考实现；新客户必须提供序列/阶段数据以重绘，不能只换标签。没有原始分项时记录限制，不从像素反推业务数字。

## 小时图及其他旧流程能力

- [时段分布参考](time-distribution.md)体现了连续时间、对象对齐和色阶定位的表达思路。具体图型先看问题和数据，不因收到参考链接就强制统一矩阵或轴向。
- 全部已选对象和时段有去向；共享原值尺度比较大小，逐对象最高值归一仅比较节奏，显示尺度说明和原值峰值。
- 连续小时轴不拆成互不对齐的两块。可按客户版式转置矩阵；不把某次转置推广成唯一方向。默认只裁全部对象共同明确为0的连续首尾，未知/内部0/微小正值不裁。全日0保留完整范围，未知与确认0分别标记。
- 不平滑或补齐未知小时。只标峰值时不能声称可查全部小时原值；需要全量标签时静态展开/分段，不能依赖交互。
- 旧A运行器的`layout/scale/labels/trim/night`选项及字段校验留在原接口；对象数阈值、窄表列数阈值是旧运行器限制，不是新视觉规范的删行授权。新类型须实现适配器并验证，不能默默退化成无关图形。

- 颜色的业务语义优先于按数值分配深浅：在岗活跃固定深色C1、未出勤固定浅色C8，按“活跃→未出勤”的业务顺序呈现；占比反转也不交换颜色。此类语义映射须显式配置，其他无语义的构成仍按占比降序配深浅色。

## 当前报告的已确认配置

以下仅用于现有报告回改，不是所有客户必须采用的模板。新数据或新任务仍按上文选图；用户提供的新参考用于分析原则，不自动覆盖此报告配置。

- 当前异常类型顺序为缺勤率→取消率→迟到率→早退率→缺卡率，不按数值变动重排。早先的异常分流图及横向条形图方案已由下述卡片柱图覆盖，不再作为并列执行要求。

### 出勤异常率卡片柱图（2026-11-10 最新确认）

当前报告按 Figma `设计参考` 使用 `anomalyCards`：五张等宽、无描边的独立浅底卡片，每张卡完整包含类型、当前值、较上月与对应柱形，卡间距6px；保留清晰的单项分组。下方64px高的柱图区保留相同量程和对齐的零基线，但不绘制刻度线、网格线或基线。普通卡使用浅中性填充，异常卡使用浅危险色填充，均不加描边。柱图保留主色/危险色填充以编码数值。文字区与图形区分离，不把文字叠在填充上。固定顺序为缺勤率→取消率→迟到率→早退率→缺卡率；普通项C1、异常项危险色，五张卡片统一8px圆角。此呈现覆盖当前报告此前的横向条形图要求；独立总异常率和已有比较信息继续保留。总指标区沿用通用上下布局：指标名称、主数值、环比依次排列，行业均值比较提示置于其下方，复用通用满宽 badge 的底色、图标、圆角与内边距，不另做右侧小标签。

所有卡片共用零基线和同一量程；量程保留在配置中，不在卡片底部展示量程文案；默认0–10%，超过时所有卡片共同扩大量程，不能逐卡归一、放大小值或暗示五项构成总量。填充高度由原始数值计算，不照抄设计稿像素。类型与环比数值使用12px，“较上月”辅助标签使用10px浅灰色（当前卡片的明确例外），当前值使用已有20px档位与MiSans Semibold，百分号独立使用12px常规字体；保留环比正负号及改善/恶化语义色，窄屏不缩字。五张卡片的信息行共同对齐，底部柱图保持相同高度、零基线与量程，长标题换行时同步增高该信息行，不挤压个别柱图区。只同步呈现，设计稿示例数值不覆盖客户数据。
