# 报告字号与文字排版

本规范来自2026-11-10用户确认的报告样式。控制视觉层级所用字号数量，不改变业务数据、比较口径、图形类型、模块数量或内容完整性。用户后续明确要求优先。

## 七档字号

以393px逻辑宽度为基准，320、375、393、430px共用以下字号。导出2倍像素图片时整体等比导出，表中数值仍指逻辑像素。

| Token | 字号 | 用途 |
| --- | --- | --- |
| `--font-display` | 36px | 封面标题、正文核心指标、章节编号 |
| `--font-metric` | 28px | 封面指标、小指标卡、圆环中心数字 |
| `--font-chapter` | 20px | 章节主结论 |
| `--font-module` | 16px | 图表、模块及内嵌模块标题 |
| `--font-body` | 14px | 正文、原因分析、建议行动、指标名称、主要图例 |
| `--font-caption` | 12px | 环比、标杆说明、表格、排名、案件明细 |
| `--font-micro` | 10px | 仅限下列受限场景，不用于业务正文 |

10px例外：坐标刻度、图表次要样本量、堆积图内部标签、漏斗紧凑比较提示、排名图标内部数字，以及封面双列卡片的紧凑环比/行业比较行。

HTML在根节点统一定义这七个CSS变量；组件按用途引用变量，不再添加11、13、15、18、24、26、30、34、44px等临时字号。不要对SVG源代码中的坐标或缩放补偿值机械替换。

## 字体与视觉层级

- 主数值使用MiSans Semibold；正文、表格、环比和图表小数字跟随系统中文字体，如PingFang SC、Microsoft YaHei。不要把所有数字都设置为MiSans。
- 字重以400和600为主，正文常规，标题及重点加粗；同字号的信息通过字重、已有语义颜色和间距区分，不以不断新增字号建立层级。
- 原因分析与建议行动正文均为14px，保留各自已有的底色、图标和间距。
- 数字、单位、比较标签及变化值保留独立元素，不添加中间分隔点。改善/恶化颜色继续按业务方向与既有品牌规则处理。
- 章节编号使用36px，避免以更大的装饰数字抢占核心指标的注意力。

## 周期变化成为主视觉时

常规环比仍按12px辅助信息处理；仅当模块主题明确强调同比/环比变化时，变化值可作为主指标采用已有20/28px与MiSans Semibold，本期值按场景使用28/36px。比较期标签和单位仍独立且次要，不扩大到普通比较行。具体结构见[周期变化重点展示](period-change.md)。

## 封面比较行

- 双列封面指标卡中的“较上月/周”和“较行业/标杆”优先放在同一行，允许用已有10px档位。
- 可采用组间6px、组内2px间距；320px等窄屏可收紧到组间4px、组内1px，并适度调整卡片内边距。这是可用适配方式，不要求对其他布局机械套值；实际取值须检查当前生效样式，不沿用被后续CSS覆盖的旧值。
- 每组标签与数值保持完整；保留正负号和全部比较信息，不用缩放、截断、省略或小于10px的文字强行塞入。
- 当前参考内容在四种验收宽度均应为一行。未来客户内容确实超长时允许整组自适应换行，不能承诺任意内容永久单行。

## 表格与窄屏

- 宽度和图形高度的调整、标签重排及动态测量见[移动端布局规则](mobile-layout.md)。窄屏适配不等于整图缩放，字体保持用途对应的字号档位。
- 表头需要换行时尽量按语义均衡分行，如“赔付 / 人数”，避免“赔付人 / 数”。HTML可用`text-wrap: balance`，渲染后检查实际断行；需要时采用有意义的词组边界。
- 同一行表头及其他单元格垂直居中；名称列保持左对齐，数值列保持右对齐。“居中”不代表把所有列改成水平居中。
- 表头左右外缘保留8px安全边距，窄屏可降至6px，只调整首列左边距和末列右边距，不把每列都加宽。
- 金额和计数不拆行，表格保留12px。先调整列宽、内部留白和文字换行；不能把数字拆为两行或改成10px以逃避排版问题。
- 保留已有无描边表格及表头四角8px圆角。
- 正文使用自适应高度。窄屏沿用七档字号，优先换行、调整留白与布局，不新建窄屏专用字号。

## 验收

生成或修改后，实际渲染320、375、393、430px四种宽度并查看局部截图，重点检查封面比较行、月份费用表、排名、图例和分析正文：

- 实际文字字号仅使用七档；检查可见文字，不把图标宽高误当字号。
- SVG的字号以最终屏幕效果验收。若viewBox缩放，需要用目标字号除以实际缩放比例做补偿，不能仅检查SVG内部的font-size数值。
- 无横向溢出、文字裁切、相邻标签重叠或金额拆行；父容器`overflow:hidden`隐藏内容不算通过。
- 表头上下行尽量均衡、同排垂直居中，两端安全边距符合要求。
- 保留原有模块、行数、数据精度、比较信息和语义颜色。样式调整不意味着可以重写业务结论。

在周报月报项目中使用时，先读取项目`outputs/报告标准模板/README.md`，复用`report.css`、`report.js`与`build.py`，避免生成另一套相互冲突的字号实现。其他项目没有这些文件时直接按本规范实施，不依赖该路径才能使用本技能。

## 关联间距与排名表

同一问题的组标题、内容及组内子卡片间距16px，独立模块间距32px，组内间距小于组间间距；用分组容器表达关系，不以负边距拼凑。TOP排名使用带表头表格，排名列的表头、前三名警告图标与其余数字全部水平居中，共用列中心线；名称左对齐、数值右对齐，其余表格规则保持一致。

正文核心指标名称统一16px，与模块标题一致；封面指标名保持14px。异常指标紧凑卡中的“较上月”标签允许10px浅灰，环比数值仍12px。这是用户确认的局部例外，不扩大到业务正文。封面间距详见布局规范的最新补充。
