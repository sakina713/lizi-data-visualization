# 周期变化：本期规模与变化重点成组展示

从用户2026-11-11提供的业绩比较截图提炼。适用于主题明确强调同比、环比或前后改善的模块；是一种可选表达方式，不把所有报告的辅助环比都放大，也不固定使用参考图的红橙、蓝金、粉色、渐变或装饰箭头。

## 按比较任务选择结构

| 读者的问题 | 可采用的形式 | 信息关系 |
| --- | --- | --- |
| 本期做到多少，比上一期提升多少 | 本期值＋变化值的指标卡 | 名称、本期值及单位组成规模区；比较期标签、带符号的变化值组成变化区。空间够时左右并排，窄屏同卡上下排列 |
| 多个关键指标各有怎样的变化 | 重复的指标行或并排指标卡 | 每项独立成组，名称、主值、变化标签及变化值使用一致的对齐线；不同量纲不共享柱高比较 |
| 两期实际规模差多少 | 两条短柱/横条＋差值或变化率 | 两期同指标共用零基线、单位和量程，直接标周期与原值；本期突出、参照期弱化但可读 |
| 同时看同比和环比 | 同一主值下并列两个比较组，必要时分别配两期小图 | 同比和环比明确写比较期，不能将两种基准混在同一“增长”标签下；复用本期值，避免多个大数值重复抢焦点 |
| 变化是否持续 | 真实多期柱图或折线＋重点期标注 | 时间顺序和间隔真实，重点标当前期与关键变化；两期数据只支持两期比较，不推导持续加速 |

主问题是增长率时，变化值可提升为主数值层级，本期规模仍保留。主问题是规模时，本期值优先，变化值为第二重点。保持名称、当前规模、比较期和变化幅度可辨，不让读者只看到一个脱离规模与口径的“+百分比”。

## 视觉层级与适配

- **成组而非分散**：本期值与变化值共享卡片/行及背景关系；间距小于独立指标之间的间距。需要时用轻量分隔线辅助分区，优先用留白，不堆叠外框、粗线、图标与装饰。
- **规模与变化各有角色**：本期主数值用主题主色；变化按改善/恶化语义着色，或采用已确认的品牌强调色。变化期标签及口径说明使用次要文字色；不复制截图配色，也不把普通增长统一当成危险色。
- **按角色使用已有字号**：常规辅助环比仍12px。仅在本模式中，成为主视觉的变化值可按指标数值使用20/28px档位，主值按场景用28/36px；不新建字号。提升为主指标的数字可用MiSans Semibold，单位与比较标签独立且较弱，普通环比小数字仍跟随正文。
- **图标服务信息**：箭头可放在变化值旁作轻量方向提示，向上代表数值增加、向下代表减少。成本降低可用向下箭头＋正向色；异常率上升应使用负向色。正负号、周期标签和文字不能被箭头替代；持平不用上升箭头，未知不用方向箭头。
- **历史参照弱化但不失真**：两期柱条可用本期主色、参照期浅色/中性色，这是周期角色映射；前期更大时也不交换颜色。两期标签和值保持清晰，几何按原值计算，不以放大本期、缩短前期来制造提升感。
- **移动端重排**：空间不足先改为同卡上下结构或单列卡片，不挤压数值、拆开单位或缩小字体。两期小图可以降低绘图区高度，保持共同比例；同比/环比两组应各自完整，不串项。遵守[移动端适配规则](mobile-layout.md)。

## 比较口径先于增长叙事

- 写明是较上月、较上周、较上季、同比还是指定前后时期；同比指上年同期，不等于上一周期。期间长度、累计/单期、组织范围、单位及统计口径应可比；不完整周期须标明并采用已确认的可比口径。
- 相对变化率按原始值计算`(本期÷比较期−1)×100%`，最终百分比保留一位小数；金额两位、计数整数，遵守[数据展示契约](data-display.md)，不沿用参考截图的展示精度。
- 变化率、绝对增量和百分点分别说明：金额增长额用金额单位，百分比指标的绝对差用“个百分点”，相对变化用“%”。例如80.0%到84.0%，相对变化为+5.0%，绝对变化为+4.0个百分点，不混写。
- 比较期缺失或为0时相对变化显示“—”，不画无限增长；两期已知时可按任务显示真实绝对增量。负基数或盈亏转换先核实业务计算口径，不机械给出“增长率”；必要时直接呈现两期值与已确认的变化说明。
- 同比与环比、“提升”与“增速提升”分别判断。增速提升需要两段可比增长率作为依据；只有本期高于上期，不能称为“持续增长”“加速增长”或“再创新高”。已确认结论可以强调，不能从参考标题移植业务结论。

## 箭头、趋势与预测的边界

- 数值旁的小方向箭头是提示，不是数据曲线；不按箭头长度、弯曲程度暗示增幅大小。
- 横跨多根柱的上扬曲线容易被读成真实趋势、加速或预测。优先使用数据绘制的折线，或将方向提示放回数值旁；不能画一条装饰性上扬弧线穿过波动/下降数据。
- 只有已提供真实序列才画历史趋势；只有已确认预测数据才画预测柱/线。预测注明“预计/预测”、时期及必要依据，使用虚线/纹理等明确区分，与实际数据共享正确尺度；不只靠渐变变淡或一个含糊的E区分。
- 图形不因渐变而失去边界或基线。没有预测值就不补未来柱；截屏中的未来期、柱高和箭头不能作为业务数据。

## 验收

检查当前值、比较期、变化口径与符号是否一致；两期条长是否共用尺度；规模与变化的阅读顺序是否清楚；正负色是否符合业务方向；预测是否明确分开。在320/375/393/430px核查同项分组、单位、长名称与比较信息完整。此规则不意味着现有HTML运行器已经实现该新组件，落地时仍须实现并渲染验证。
