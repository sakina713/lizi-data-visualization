# 布局、主题与组件

本页维护用户明确确认的通用样式与标明范围的当前报告配置。新提供的Figma参考不自动覆盖这些约定；图表的具体形式、颜色编码和内部布局仍须按数据类型、业务含义与内容密度判断，不以复刻参考为目标。

## 结构与关联间距

- 手机宽度、图形高度及内容密度的适配按[移动端布局规则](mobile-layout.md)执行。通用间距用于组织关联关系，图表内部尺寸由实际内容决定；不得通过固定高度或裁切强求参考稿形状。
- 报告身份区交代品牌、报告名称、精确周期和当前范围；核心KPI单独成区。当前模板封面短KPI双列等宽、同行等高，不能为了凑数擅自更换固定指标。
- 本月亮点在需要关注之前。亮点用白底文字区，关注用浅语义色面板。一章只留一句易懂的主结论，随后给图表证据及必要行动；结论中说明具体哪里好/差，不堆数据、不使用难懂业务术语。
- 原因分析：图表下方浅红底、红边框、红文字及已有分析图标；与事实区分。建议行动：已有浅蓝/品牌浅色卡片。不要改成灰色脚注或另开交互弹窗。
- 393px为当前逻辑宽，页面外边距16px、主卡内边距20px；窄屏可用12/16px。主卡圆角20px、封面卡22px，内容高度自适应，不固定长图高度。
- **强关联16px、独立模块32px**：组标题到内容、同一问题下子卡片之间、图表到原因分析使用16px；不同问题的模块间32px。用语义分组容器承载，隐藏/重排后按可见分组重新计算，不用负边距拼凑。
- 标题/数字/比较信息有清晰层级，所有字号按[字号规则](typography.md)。留白不能通过压缩正文或遗漏证据获得。
- 模块、指标可增删重排，编号连续；保持顺序、子群体和业务关系。排序规则见[图表规则](charts.md)。

## 颜色

- A取自客户Logo或已确认品牌主色；T1用于关键数值和主要强调，T2用于常规标题及正文。T2是低饱和的品牌偏色深中性色，不能把高饱和主色直接套在全部正文上。
- 黑白Logo可采用已确认的微蓝中性色方案；黄色品牌的浅色背景文字可采用已确认的深棕色方案。没有通用取色公式可保证每种品牌的可读性；先复用客户已确认色板，再检查对比，不能把历史示例色值当作所有品牌固定值。
- C1—C8为同品牌色相、由深到浅且逐步柔和的色阶；主要文字不使用浅C7/C8。不要沿用旧客户色板或随机分配图表色。
- 默认正向绿色、负向及警示红色。改善/恶化按指标方向判断，成本下降可以为正向，不能把“上升”一概标为好。
- 比行业优秀的提示默认底色`#F0FBF7`，配正向图标；红/橙品牌若已有用户确认的正负色反转，沿用该配置，优秀提示底色用主色同系浅色，不能强制绿色。无用户确认不自动反转。
- 本月亮点图标与标题同色。普通数据比较统一主色，异常才用危险色；详细编码见图表规则。

默认绿色取色板：以用户指定的设计参考实际填充色为准（2026-11-10读取）。未指定客户主题时使用此套；已确认的客户主题可覆盖。当前已确认的蓝色品牌报告属于客户主题，不再作为通用默认值。

## 圆角一致性

同类元素沿用相同圆角：主卡20px、封面卡22px；表头、分析/行动容器及分流图紧凑行业比较提示8px。胶囊或大号比较条按已有组件半径，不把不同尺寸元素机械统一为同一半径。带底色提示不得因局部实现遗漏而变成直角矩形。

## 表格、下钻、案件与标识

- 表格统一带表头底色，表头四个外角8px圆角；无外框及行分隔描边。边距、均衡换行和垂直居中遵守字号文档。
- TOP排名显示明确列名，保留对象、分子/分母、百分比及用户要求的行数；不把字段口径放在表外让读者猜。排名列全部居中，包括表头、圆角警告三角和其余数字；前三名不铺整行警示底色。三角内数字略上移以视觉居中。
- 下钻明细沿用“其中 · 名称＋比较＋数值”的次级样式。父项和子项不是同层类别，不能重复计入总量。配置可隐藏children，保留组件能力；当前费用构成仅显示“薪资总额”，其细分暂不展示，这不是所有费用图的永久禁令。
- 案件状态使用当前项目已授权组件库的原始SVG：已赔付对应完成，理算中对应时间，不予受理对应关闭。图标14px，与状态文字同色、居中对齐；不换成文字符号、emoji或自绘替代。店名14px半粗T2，状态12px常规，理算中使用次要灰色。发布包不附带内部组件库素材，使用者需提供对应原始资源并保留来源记录。
- 平台标识使用项目提供的原始资源，不手写或重绘；底部数据来源按真实数据填写。发布包不附带品牌Logo。
- 客户Logo使用所提供原始素材，保持比例；缺素材时不仿造官方Logo。离线HTML应内嵌字体和所用资源，避免断网丢图。

## 记录型信息的卡片化

- 案件、事件、处理进度等以逐条理解对象为主的信息，优先从原始表格提炼关键字段，设计为卡片或分组卡片列表；不必照搬所有列。
- 先判断读者需要识别谁、发生了什么、当前进展和结果。保留对象名称、关键日期/事实、状态，以及金额/处理结果等与当前问题有关的内容；允许省略不影响理解的内部编号、重复字段和后台管理信息。保留区分同名记录所必需的信息。
- 首行突出对象名称，状态作为次要信息放在右侧；下方放日期和事件摘要，必要时以浅底区域承载结果或赔付明细。使用已有字号、颜色、圆角和间距；名称的视觉层级高于状态，长内容自适应换行。
- 字段精简只影响展示，不删除源数据，不减少应展示的记录或隐藏异常。重要条件、单位、比较依据与用户明确要求的字段仍须可见；在配置或交付记录中留存字段映射及省略理由，不把这些实现说明放进报告正文。
- 排名、跨对象横向比较、月度费用矩阵及精确查数继续优先用带表头的表格。不能把所有表格机械改成卡片。

- 颜色的业务语义优先于按数值分配深浅：在岗活跃固定深色C1、未出勤固定浅色C8，按“活跃→未出勤”的业务顺序呈现；占比反转也不交换颜色。此类语义映射须显式配置，其他无语义的构成仍按占比降序配深浅色。

### 当前报告的封面间距与正文指标标题（2026-11-10 确认）

- 头部及封面关键卡片间距以青色参考稿 `设计参考` 为准：品牌区顶部24px、左右20px；品牌行与主标题间隔20px，标题与日期间隔8px；日期行到关键卡片区间隔28px。封面主标题36px/48px行高，日期16px/22px行高。
- 封面关键卡片双列布局，横纵间距10px，外层上下20px、左右16px；卡内14px留白、元素间距8px，标准393px宽下每卡110px高。内容高度仍自适应，不锁死长文本。封面指标名14px/18px，数值28px/32px，比较信息沿用10px/14px单行规则。
- 正文核心指标名称（如“本月需求满足率”“本月高效能工时占比”“本月出勤异常率”）统一16px，与模块标题一致；不把封面指标名、图例或普通说明一并放大。
- 出勤异常模块标题层级按设计稿：先显示“本月出勤异常率”及总值/比较，再显示“异常指标 · 取消率异常高”和五张卡片。视觉标题同步不覆盖用户底表数值或Figma中另行保留的内容。
