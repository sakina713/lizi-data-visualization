# 渲染与验收

- 使用本地确定性HTML/SVG或已实现的图表适配器。HTML离线内嵌资源，正式输出可直接交付HTML。用户需要PNG时等待字体、图标、图表布局完成后截图。
- 当前标准393 CSS px；验收320、375、393、430px。2倍导出393 CSS px应得到786物理像素，不把逻辑宽和导出分辨率混淆。用户指定其他尺寸时按该尺寸复验。
- 不固定全文高度、正文高度或用隐藏溢出掩盖裁切；长图超环境限制按完整模块拆图并说明顺序，不静默裁尾。
- 实际检查头/中/尾与最长标签、密集月份表、排名、分析区；文件存在或脚本返回ready不等于视觉通过。
- 移动端除检查溢出外，还按[宽高与密度验收](mobile-layout.md)检查：窄图是否过高、是否有无效留白、降低高度后是否仍能比较、文字是否随SVG缩放变小，以及字体/容器变化后标签是否重新对齐。记录视口宽度与实际报告/绘图区宽度；有最大宽限制时不能把430px视口误称为430px内容验证。

交付前确认：

验收目标是表达准确、重点明确、信息完整和风格统一。除用户明确要求复刻外，不以与参考稿坐标、色值、尺寸逐一相同为通过标准。

1. 七档实际字号、字体已加载；图标/Logo原资源正确；颜色和状态语义一致。
2. 无横向溢出、重叠、裁切、数值换行；表头安全边距、均衡断行及排名列居中。
3. 强关联16px、独立模块32px；隐藏/重排后编号、分组和可变正文布局仍正确。
4. 排序、比例、参考线位置、饼环白线、图例与实际数据一致；SVG缩放后文字可读。
5. 封面与正文共享指标；环比、标杆、绝对差、分子/分母、样本量和明细行数完整。
6. 记录型卡片核查关键字段与源数据映射、字段省略理由、记录数量及异常是否保留；对象名称比状态醒目，精简字段不改变事实。
7. 当前视角的地域/门店/人员名单正确，原因推断与事实区分；未授权删减记为缺口而非已完成。
8. 图表标签与标题关注的指标一致；有主系列的堆积/趋势图优先标主系列各期关键值，非重点分段保留几何和图例。检查没有因精简标签误删系列、隐藏必要异常、混淆人数/工时占比，或删除原本用于逐格查数的热力矩阵数值。
9. 密集漏斗核查左右分区、阶段数量与截面的指向、转化率与相邻阶段的对应；连线不穿字、不交叉，长比较信息不挤压图形。示意/强调形状不能冒充真实人数比例。
10. 有聚焦对象的比较图能迅速识别目标，同时对照名称、必要读数、样本量、基准与异常仍清晰。重点来自明确对象/系列映射，不是默认最大项；弱化不改变排序、比例或原有风险/热力编码。
11. 饼/环图例的类别、色块、具体值及单位、百分比同项对应；规模与占比有清楚的颜色/字重层级，已有读数均保留。换行后不串项，下钻不重复计总，异常说明归属明确，扇区与图例同源同序。
12. 宽高适配后同组仍使用共同尺度和对齐的基线；图表不拉伸变形，圆环保持圆形。正文/图例自适应增高，标签换行与指向线同步，全部所需字段和明细仍有去向；截图须在字体与重新布局完成后生成。

13. 使用[周期变化重点展示](period-change.md)时，核查同比/环比的比较期、绝对增量与相对变化率、业务正负色、两期共同尺度及预测标记；装饰箭头不能冒充真实趋势或加速增长。

当前模板可运行`python3 build.py`后用`check.cjs`、`check-readability.cjs`和章节截图核查；这些本地脚本的依赖路径可能需适配。旧A/B运行器仅证明其原有能力；新规则若未在该运行器实现，应使用当前适配实现并说明限制，不能声称所有旧脚本自动升级。
