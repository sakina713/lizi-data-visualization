# 栗子数据可视化 Skill

将已确认的业务数据与结论呈现为层级清楚、信息完整、适合移动端阅读的图表和报告。

## 包含内容

- 根据数据关系与阅读任务选图，结合AntV方法判断适用性。
- 七档字号、语义配色、圆角、表头、排名与关联间距。
- 饼环图图例、重点突出、热力矩阵、时段分布及密集漏斗布局。
- 移动端宽度自适应、合理降低绘图区高度、标签避让与多宽度验收。
- 同比/环比重点指标卡、两期柱条对照，以及核心大数＋历史走势＋重点期标注。
- 正负向明细的分组紧凑横条、方向语义与共同尺度。
- 数值精度、环比与百分点区分、真实比例和数据完整性。

参考稿用于提炼原则；具体图型、颜色和布局随数据、主题与内容密度调整，不默认一比一复刻。

## 安装与使用

将本仓库下载到Codex的技能目录，文件夹命名为`lizi-data-visualization`，确保目录中直接包含`SKILL.md`。也可让Codex使用技能安装器从本仓库安装。

调用示例：

> 使用 $lizi-data-visualization，根据我提供的数据与结论生成移动端HTML报告；保持数据完整，突出主要指标，并检查320、375、393、430px下的可读性。

入口：[SKILL.md](SKILL.md)。详细规则位于`references/`，默认主题位于`assets/default-theme.json`。

## 使用范围

这是呈现规则技能，不是独立图表应用或自动查询工具。业务数据、口径、结论、字体及已授权的图标/Logo由使用者提供。生成图表需使用当前环境实际可用的HTML/SVG或其他适配器，并完成渲染检查。

发布包保留通用规则，不包含客户报告、客户底表、内部Figma定位信息或品牌专属素材。文档中标明“当前报告”的组件参数是有适用范围的参考配置，不强制所有项目使用。
